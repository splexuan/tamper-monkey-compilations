# Tampermonkey 脚本合集

自用油猴脚本集合，按需安装。

## 脚本清单

| 脚本 | 版本 | 适用站点 | 一句话说明 |
| --- | --- | --- | --- |
| [B站助手](#b站助手) | v1.1.0 | `space.bilibili.com` | 一键导出 UP 主全部投稿 / 合集 / 系列的视频链接 |
| [一刻相册助手](#一刻相册助手) | v1.5.0 | `photo.baidu.com` | 给一刻相册网页版加上网盘级操作体验 |
| [推特助手](#推特助手) | v0.7.1 | `x.com`·`twitter.com` | 文章代码块自动换行，一键截图并导出 Markdown |

## 安装

1. 浏览器先装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge）或 Violentmonkey
2. 打开本仓库中对应的 `.js` 文件，**复制全部内容**
3. 点 Tampermonkey 图标 → 「添加新脚本」→ 全选删除后粘贴 → `Ctrl + S` 保存

## B站助手

`B站助手-v1.1.0.js`

在 B 站页面右下角生成一个悬浮面板，把当前页面能拿到的视频链接一次性导出。

**功能**

- 自动识别页面类型：UP 主空间页 / 合集页 / 系列页
- 三种导出范围
  - **合集**：抓取该合集内全部视频
  - **系列**：抓取该系列内全部视频（旧版系列同样支持）
  - **UP 主全部投稿**：抓取该 UP 主所有投稿视频
- 在 UP 主空间页可先「列出合集」，面板中列出全部合集与系列及各自视频数，逐个点「导出」
- 结果三选一：**复制链接** / **下载 TXT**（每行一条链接）/ **下载 CSV**（含 bvid、标题、时长、发布时间）
- 面板可拖拽、可收起，样式经 Shadow DOM 隔离，不影响 B 站自身样式

**说明**

- 合集、系列两种模式免登录即可使用
- 「UP 主全部投稿」需要浏览器已登录 B 站，否则会被风控拦截并给出提示
- 抓取过程按页节流，页数与进度实时显示

## 一刻相册助手

`一刻相册助手-v1.5.0.js`

**功能**

- 顶部集中操作栏
- 单击即选、双击预览
- `Ctrl` / `Shift` 多选、拖拽框选、`Ctrl + A` 全选
- 拖拽上传到当前相册
- 无时间线文件网格，网盘式浏览
- 图片 / 视频完整缩略图
- 点击预览遮罩即可关闭
- 快速切换相册
- 小图密集模式
- 带确认的智能批量下载（每批 95 个，批间隔 2.5s）
- 自动加载更多、界面精简

## 推特助手

`推特助手-v0.7.1.js`

**功能**

- Twitter/X 文章内的代码块自动换行，不再横向滚动
- 一键截图整篇文章（最高 2.5 倍缩放，自动规避画布尺寸上限）
- 导出内嵌图片的 Markdown

**依赖**

运行时通过 CDN 加载 `html2canvas@1.4.1`，请保持网络可访问 jsDelivr。

## 约定

- 文件命名：`<助手名>-v<版本>.js`，版本号与脚本内 `@version` 保持一致
- 脚本头部 metadata 字段顺序与对齐格式保持统一
